# SF6 Reaction Trainer

## 1. プロジェクト概要

### アプリ名

SF6 Reaction Trainer（仮）

### 概要

ストリートファイター6（SF6）の対戦で必要となる反応力や状況判断力を鍛えるための、スマートフォン向けWebアプリケーション。

キャラクター風のアニメーションを使用し、以下の3種類のトレーニングを行えるようにする。

- 差し返し
- インパクト返し
- 対空

### 開発目的

- SF6の対戦で必要な反応力を鍛える。
- スマートフォンから手軽に練習できるようにする。
- 練習結果を数値化し、成長を確認できるようにする。

### 対象ユーザー

- SF6をプレイしているユーザー
- 差し返し・インパクト返し・対空が苦手なユーザー
- 反応時間や練習結果を記録したいユーザー

## 4. 画面仕様

### 4.1 ホーム画面

**目的：** 練習するモードを選択する。

**表示要素**

- アプリ名
- 差し返しボタン
- インパクト返しボタン
- 対空ボタン
- 成績・履歴ボタン（追加予定）

**動作**

- 各モードのボタンを押すと、対応するトレーニング画面へ遷移する。
- 成績・履歴ボタンを押すと、過去の練習結果を確認できる。

### 4.2 トレーニング画面

**目的：** 相手の行動を見て、適切なタイミングで反応する。

**表示要素**

- トレーニング名
- プレイヤーキャラクター
- 相手キャラクター
- 相手の行動アニメーション
- 反応用ボタン
- 現在の問題数
- 成功数・失敗数
- ホームへ戻るボタン

**基本動作**

1. トレーニングを開始する。
2. 一定時間後に相手の行動をランダムに表示する。
3. ユーザーが反応用ボタンを押す。
4. 入力内容とタイミングから正誤を判定する。
5. 次の問題へ進む。
6. 全問題終了後、結果画面を表示する。

### 4.3 結果画面

**目的：** トレーニング結果を確認する。

**表示要素**

- 出題数
- 成功数
- 見逃し数
- 誤反応数
- 成功率
- 平均反応時間
- もう一度練習するボタン
- ホームへ戻るボタン

### 4.4 成績・履歴画面（追加予定）

**目的：** 過去の練習結果と成長を確認する。

**表示要素**

- 練習日時
- トレーニングモード
- 成功率
- 平均反応時間
- モード別の成績推移

## 5. トレーニング別仕様

### 5.1 差し返し

**目的：** 相手の技の空振りを確認し、反撃する練習を行う。

**出題内容**

- 相手が通常技を出す。
- 技が空振りする。
- 反撃可能な時間を設定する。

**判定条件**

- 反撃可能な時間内に入力した場合：成功
- 受付時間より早く入力した場合：早押し
- 受付時間を過ぎた場合：失敗
- 入力しないまま終了した場合：見逃し

### 5.2 インパクト返し

**目的：** 相手のドライブインパクトを確認し、反応する練習を行う。

**出題内容**

- ドライブインパクト
- 通常技
- 何もしない行動

**判定条件**

- インパクトに対して受付時間内に入力した場合：成功
- 通常技や待機中に入力した場合：誤反応
- インパクトに入力できなかった場合：見逃し

### 5.3 対空

**目的：** 相手のジャンプを確認し、対空行動を取る練習を行う。

**出題内容**

- ジャンプ攻撃
- 地上技
- 何もしない行動

**判定条件**

- ジャンプに対して受付時間内に入力した場合：成功
- 地上技や待機中に入力した場合：誤反応
- ジャンプに入力できなかった場合：見逃し

※初期バージョンでは、実際のゲーム内の技性能やフレームデータではなく、アプリ内で設定した受付時間を使用する。

## 6. 結果の計算方法

### 成功率

成功率は、全出題数に対する成功数の割合とする。

`成功率（%）= 成功数 ÷ 出題数 × 100`

### 平均反応時間

正解した問題の反応時間の平均値とする。

`平均反応時間 = 正解した問題の反応時間の合計 ÷ 正解数`

- 単位：ミリ秒（ms）
- 正解が0件の場合は、平均反応時間を「—」と表示する。
- 反応時間は、正解となる動作の表示時点からユーザーの入力時点までを計測する。

## 7. データ仕様

### トレーニング結果

| 項目                | 内容               |
| ------------------- | ------------------ |
| resultId            | 結果を識別するID   |
| mode                | トレーニングモード |
| date                | 練習日時           |
| questionCount       | 出題数             |
| successCount        | 成功数             |
| missCount           | 見逃し数           |
| falseCount          | 誤反応数           |
| averageReactionTime | 平均反応時間       |

### 保存方法

初期バージョンでは、ブラウザの `localStorage` を使用する。

※保存データは基本的に使用したブラウザ内に保存される。別の端末との共有や同期は対象外とする。

## 8. UI・デザイン方針

- スマートフォンでの操作を優先する。
- タップしやすい大きなボタンを配置する。
- キャラクター風アニメーションで行動を視覚化する。
- 成功・失敗を色や文字でわかりやすく表示する。
- トレーニング中は不要な情報を減らす。
- 縦向き画面を基本とする。

## 9. 非機能要件

- スマートフォンの主要なWebブラウザで動作すること。
- 画面サイズに応じてレイアウトが調整されること。
- 出題と正誤判定が正しい順序で実行されること。
- 連続タップや二重入力によって判定が重複しないこと。
- 練習結果が正しく集計されること。
- アニメーションの表示タイミングと判定タイミングが一致すること。
